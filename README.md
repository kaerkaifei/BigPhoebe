# 合成大菲比 · 区域范围改版

**[▶ 在线试玩](https://kaerkaifei.github.io/BigPhoebe/)** · 原作:[mirac.asia 的《合成大菲比》](https://mirac.asia/)(v12,多边形物理 + 公共排行榜)

基于原作制作的本地改版。
**玩法、素材与界面保持原作**,仅扩大可玩的区域范围。原作版权归原作者所有;菲比形象权利归其权利人,系非官方同人作品。

## 改动内容(参考 [合成大奶娃改版](https://github.com/kaerkaifei/BigNaiWa) 的做法)

- **棋盘宽度可调**:侧栏「棋盘与自动」——宽 ±60;最小 440 = 原版;桌面最大 = 窗口拉满,手机最大 1600(超出屏幕的部分在棋盘里左右平移)
- **棋盘高度可调**:高 ±100;最小 660 = 原版,最大 3000;井深默认翻倍(660 → 1320),滚动查看井底;默认停在当前视野,「投放后回到顶部」开关可恢复自动回顶
- **页面缩放**:整页 ±10%(60% – 180%),老浏览器不支持 CSS zoom 时按钮自动禁用
- **自动释放**:开关 + 速度可选(2 秒 / 1 秒 / 0.6 秒 / 0.4 秒 / 0.001 秒连发),在棋盘宽度内随机位置投放,落点被占时自动让路
- **手机 / 电脑双端适配**:手机端拖动平移视野、点哪投哪;桌面端移动瞄准、点击投放、滚轮平移
- **尺寸记忆**:宽 / 高 / 缩放保存在 localStorage,下次打开保持原样
- **一次性新功能提醒**;页面页脚与「关于」弹窗均注明原作来源并附可点击链接
- 其余(物理引擎、合成规则、公共排行榜、音效、进化图鉴等)与原作 v12 完全一致;公共榜不可用时自动回落为本机记录

## 本地运行

任选其一:

- `python serve.py`(推荐,`http://127.0.0.1:8765`,no-cache,改完刷新即生效)
- 或直接双击 `index.html`(自动切换为本机记录模式)

## 目录说明

- `index.html` / `app.js` / `site.css` —— 原作源码 + 标注「改版」字样的追加修改(原版代码位置不动)
- `assets/` —— 原作素材:play-*.webp 游戏贴图、phoebe-*.png 原图(图鉴详情)、assets/audio 音效
- `_mirac_orig/` —— 从 mirac.asia 下载的原作文件原样备份,便于对照
- `_rebuild_backup/` —— 早期重写版(非原作源码)的备份,不需要可整目录删除
